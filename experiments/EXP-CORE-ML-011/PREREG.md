# EXP-CORE-ML-011: G1 clearance ODE and G2 Poisson shot-noise mechanism validation

## Status and scope

This protocol is committed before changes to the G1/G2 result-producing simulator paths, its parameter profile, or the study runner. It registers a synthetic mechanism-validation study, not model selection, calibration to patients, or clinical-performance evidence. Existing studies and generated artifacts remain historical and will not be overwritten. The changes are limited to the simulator mechanism discrepancies identified in Q-7 package B: G1 lacks secretion/clearance dynamics and G2 uses a fixed small count of persistent steps instead of a Poisson shot-noise process.

## Questions and estimands

1. Does G1 implement the registered continuous-time first-order marker kinetics equation, including irregular observation times, with numerical error bounded against its analytic solution?
2. Does G2 generate a recurrent-event shot-noise marker process with the registered Poisson rate, event-amplitude distribution, and clearance kernel, and does its event-count distribution agree with the registered Poisson law across independent synthetic replicates?
3. Do the exported latent states and observed marker trajectories obey the configured secretion, clearance, compartment, and event-time contracts without outcome leakage or dependence on visit density?

The estimands are mechanism-level numerical and distributional properties under the synthetic profile below. They do not estimate human biological parameters or establish clinical calibration.

## Registered mechanisms

All coefficients and distribution parameters are read from a new versioned simulator profile. No new coefficients may be hidden in Python defaults.

- G1 continuous marker state for marker `m` follows `dC_m(t)/dt = q_m * B_m(t) - k_m * (C_m(t) - C_m,baseline)`, where `B_m(t)` is the configured compartment-weighted latent burden, `q_m >= 0` is the configured secretion coefficient, and `k_m > 0` is the configured clearance rate per day. For piecewise-constant burden over interval `[t0,t1]`, calculate the exact transition `C1 = C0*exp(-k*dt) + (C_baseline + q*B/k)*(1-exp(-k*dt))`; the independently implemented reference solver uses daily-step RK4. Observation visits are irregular; state propagation must not depend on adding or removing intermediate measurement visits.
- G2 event times before the true recurrence time are a homogeneous Poisson process with configured rate `lambda` per day; the process is stopped at recurrence, competing event, or administrative follow-up. Event amplitudes are independent draws from the configured positive distribution. Each event contributes `A_i*exp(-k_m*(t-t_i))` to each configured marker from `t_i` onward. The event-time and amplitude draws use independent, explicitly derived seed streams. A patient without latent recurrence has no recurrence-linked shot-noise events. Clearance is continuous between irregular visits.
- Compartment routing and marker-to-compartment weights are configuration values. Existing clinical event labels, competing-risk/censoring behavior, observation/missingness, verification, and feature definitions are held fixed. This study does not tune these mechanisms or use clinical calibration targets to alter parameters.

## Synthetic design and seeds

- Profile: new `mechanistic_core_v4` profile, with all new values explicitly labeled as synthetic stress assumptions and not literature- or patient-calibrated.
- Mechanism unit tests use hand-constructed trajectories and analytic solutions; they do not read frozen cohorts.
- Distribution study: 1,000 independent synthetic patients for each of G1 and G2, with five independently seeded replicates per mechanism (10,000 patient-mechanism draws total). Base seed `20261101`; mechanism offsets G1 `100000`, G2 `200000`; replicate offsets `10_000*r`; patient offset is its zero-based index. Derive separate NumPy `SeedSequence` child streams for patient-level parameters, event times, event amplitudes, visit schedules, and measurement noise. Do not share patient IDs or random streams across replicates or mechanisms.
- Follow-up is 730 days. Visits are generated by the existing configured schedule and are not used as integration steps. Event processes are simulated over the full follow-up interval, truncated at the true recurrence time and competing event as specified in the profile.

## Analysis and acceptance criteria

- Report each replicate separately, plus aggregate numerical/distribution summaries; never suppress a failed replicate.
- G1 exact-transition absolute error against the independent RK4 reference must be at most `1e-6` marker units for registered test cases. Removing intermediate observation visits while keeping the same seed and latent path must leave values at common visit times within `1e-10`.
- G2 event counts per replicate must be retained. Across the pooled registered independent draws, compare the total event count with the exact Poisson distribution having mean equal to the configured rate multiplied by total eligible person-time; report the exact two-sided p-value and test statistic. Conditional on each patient event count, normalized event times must pass a one-sample uniform KS diagnostic at alpha `0.01`; report its statistic and p-value. Both tests are synthetic generator diagnostics, not proof of biological realism.
- All outputs must be finite and nonnegative where the mechanism requires it. No-recurrence controls must have zero recurrence-linked G1 burden and G2 events. At least one irregular-visit metamorphic test verifies common-time invariance. Future event times, labels, anomaly flags, and latent truth must not appear in the feature frame.
- Any failed registered criterion is reported as failed; do not tune parameters or alter tests using these draws. A correction after registered output access requires a new experiment ID and seeds.
- Record distributions, configured values, numerical error, event-count summaries, diagnostics, and seeded integrity canaries in `results.json`. Render `REPORT.md` from saved JSON and verify byte parity. All output artifacts include hashes and code/environment provenance.

## Integrity and execution order

1. Commit this preregistration alone.
2. Implement the new versioned profile, G1/G2 mechanisms, independent reference checks, unit tests, and runner. Commit code/tests before the registered study run.
3. The runner refuses a dirty worktree or pre-existing access/results/report artifacts. It records exact source, preregistration, runner, simulator, environment-lock, and profile hashes before generating output. Generate the registered outputs once; preserve failure output and never reuse these seeds for a corrected run.
4. Tests may use only the explicitly registered hand-constructed cases and must not run or inspect the 10,000 registered patient-mechanism draws.

## Limits

This study tests implementation fidelity to equations and synthetic configuration, not whether those equations or parameters are biologically correct. The new parameters are stress assumptions, not sourced patient estimates. It cannot close the MASTER_PLAN simulator calibration targets, establish transport to real cohorts, or validate recurrence prediction. Any model trained on the corrected generators requires a separate preregistration and fresh cohorts. EXP-CORE-ML-003/004/007/008 and prior output files remain untouched and cannot be relabeled as results under this mechanism.
