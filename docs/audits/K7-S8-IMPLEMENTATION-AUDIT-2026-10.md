# S8-K7 implementation and evidence audit

Date: 2026-10-20. Scope: `docs/studies/PREREG-S8-K7.md`, `packages/vigil-ml/vigil_ml/causal_k7.py`, `scripts/run_study_s8_k7.py`, and the committed JSON/Markdown output.

## Findings

1. **Primary AIPW is not cross-fitted.** The preregistration names cross-fitting in its analysis plan, but `estimate_effects` fits the propensity model and both outcome models on the full cohort, then predicts on those same rows. This is a material implementation/protocol mismatch for the primary estimator. Cross-fitting reduces overfitting and nuisance-estimation bias in orthogonal-score inference ([Chernozhukov et al., 2018](https://academic.oup.com/ectj/article/21/1/C1/5056401)).
2. **Propensity support differs from the registration.** The registration states `0.01 < e(X) < 0.99`; `TargetTrialEmulation` clips to `[0.02, 0.98]`. It also requires maximum stabilized weights at most 10, while source code truncates only above the cohort's 99th percentile, which does not guarantee that maximum.
3. **The E-value point estimate uses the bootstrap mean.** `_ci` returns the bootstrap mean in slot 0, and `bootstrap_inference` passes that mean to `compute_e_value` as its point estimate. The registration calls for the original estimator point estimate and confidence limit nearest the null. The E-value is a sensitivity quantity, not a confounding detector ([VanderWeele and Ding, 2017](https://www.acpjournals.org/doi/10.7326/M16-2607)).
4. **Undefined risk ratios are fabricated as 1.0.** Naive, IPTW, g-computation, and AIPW branches substitute `1.0` when a denominator is zero; naive risks also substitute zero for an absent treatment arm. These values can look like valid null effects and must become explicit undefined/error outcomes.
5. **The simulated exposure can disagree with its definition.** The cohort generator first draws binary `treatment`, uses it directly in the outcome equation, then independently draws delays from overlapping normal distributions centered at 85 and 40 days and clips only to 14–180. It does not ensure `treatment == (delays_days > 56)`, though the report defines treatment as delay greater than 56 days. Thus the known causal effect is assigned to a latent strategy label that may disagree with the displayed delay exposure.
6. **The causal-effect parameter is mislabeled in the API.** `true_causal_rr` is exponentiated as a coefficient in a logistic outcome model, so it is a conditional odds ratio; the code separately computes the marginal potential-outcome risk ratio. The report explains non-collapsibility, but the generator argument still names the conditional odds ratio as an RR.
7. **Run provenance is incomplete.** The registration specifies N and bootstrap count but not the runner's data seeds or bootstrap seed. The JSON has no source SHA or completion manifest, and repository search found no canonical K7 frozen-access record. The report also embeds a machine-specific `file:///docs/...` registration link.

## Disposition

The old JSON and Markdown remain byte-for-byte historical artifacts; their numerical findings are not current model-selection or validated causal evidence. `EXP-S8-K7-001` is retired and the old runner fails closed before fitting or writing. Do not backfill missing access/provenance from inference. A replacement requires a new experiment ID, explicit seeds and complete estimator contract in a committed preregistration, implementation/tests frozen at a recorded source SHA, access logging before cohort generation, and a hashed result manifest. No replacement cohort was generated in this audit.
