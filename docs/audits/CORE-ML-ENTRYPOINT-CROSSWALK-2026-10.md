## Closure state

### Q-7 provenance correction

When `WindowedFeatureExtractor.transform_cohort` receives an `is_synthetic` observation column, it now rejects non-boolean flags, mixed synthetic/non-synthetic rows, and a supplied `synthetic_only` declaration that contradicts those row flags. Untagged external frames retain explicit-or-unknown provenance semantics. This checks provenance consistency; it does not independently authenticate the source.

### Q-7 treatment missingness correction

`extract_features_at_visit` now keeps null `treatment_active` unknown regardless of `synthetic_only`; known inactivity must use the explicit `none` sentinel. This avoids interpreting missing treatment status as no treatment. Focused feature tests verify both real/unknown and explicitly synthetic/unknown inputs; historical model results were not regenerated.

### Q-7 target provenance propagation

When observation rows carry homogeneous boolean `is_synthetic` tags, `transform_cohort` now derives the target's `synthetic_only` metadata from those tags. An explicit declaration must agree; mixed or malformed tags fail closed. Untagged frames remain unknown unless the caller explicitly declares provenance. This preserves an existing source fact in the fit contract and does not alter target values.
