# ADR-0045: Fit verification propensity on development data

- **Status:** Proposed for Q-7 overseer review
- **Date:** 2026-10-19
- **Decision owners:** Q-7 executor, subject to overseer review

## Context

The partner secondary-analysis path estimated inverse-probability-of-verification weights from verification status in the same test cohort whose metrics it reported. It also replaced missing verification covariates with literal zero, without recording missingness. This mixes test information into an evaluation estimator and can create an artificial covariate value.

## Decision

Fit the verification logistic model using only the first landmark of development patients. Fit each covariate median on that development cohort and include a missingness indicator for every imputed covariate. Apply the frozen transform and model to test patients, then pass those probabilities to the evaluator. Require complete binary verification status in both cohorts and fail closed for a one-class development mask, a wholly missing development feature, or unsupported test probabilities/metrics. Expose propensity and effective-sample-size diagnostics. Preserve the existing in-cohort evaluator path for explicitly registered synthetic estimator studies; held-out partner evaluation must use supplied development-fit propensities.

## Consequences and limits

This removes direct test-cohort fitting and literal-value imputation from the partner report path. It does not establish conditional exchangeability, positivity, a correct verification model, or mechanism stability. IPW is not identified for outcome-dependent missingness without additional assumptions or data. The partner analysis remains proposed pending clinical/statistical ratification and a frozen protocol; this decision does not authorize real partner data access.

## Evidence

- Regression tests cover development-only fitting, development medians, explicit missingness indicators, and fail-closed incomplete verification status.
- `experiments/EXP-CORE-ML-010/PREREG.md` registers a synthetic independent-development/test validation before its runner and result access.
- The corrected deterministic synthetic partner rehearsal is generated by `scripts/run_partner_dry_run.py` and checked by `tests/clinical/test_partner_analysis.py::test_committed_dry_run_reports_reproduce_byte_for_byte`.
