# ADR-0043: Reject invalid evaluation probabilities

## Status

Accepted for the Q-7 evaluation-contract repair. This improves metric input
integrity; it does not validate model performance or the clinical estimand.

## Context

The Brier and calibration functions clipped model predictions to `[0, 1]` before
scoring. This silently repaired invalid model output, allowing an out-of-range
prediction to receive a plausible score. The unweighted calibration function
also returned ECE and MCE of zero for an empty input, and IPCW calibration
coerced event codes to integers before validation. The survival decision-curve
function did not validate its risk and threshold inputs and contained an
unused prevalence expression with a literal `0.05` fallback.

## Decision

- Validate probability vectors as one-dimensional, finite, and within `[0, 1]`;
  reject invalid values instead of clipping them.
- Validate calibration labels, IPCW event codes, and supplied weights before
  computing calibration summaries.
- Return undefined (`NaN`) calibration values for an empty cohort.
- Validate decision-curve threshold inputs and return undefined net-benefit
  arrays for an empty cohort. Remove the unused fallback calculation.
- Preserve the existing software default DCA grid for compatibility, but do not
  treat it as a registered study threshold. Q-7 must trace each result-producing
  caller to a preregistered grid; the default must be removed or made explicit
  before any new DCA evidence is produced.

## Consequences

Existing calls that passed invalid probabilities, fractional event codes, or
invalid weights now fail clearly rather than yielding repaired or misleading
results. Empty calibration no longer looks perfect. No study output is
regenerated by this source change. The default DCA grid remains an open
registration issue, recorded in the Q-7 repair plan.
