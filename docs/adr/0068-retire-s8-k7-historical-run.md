# ADR-0068: Retire the historical S8-K7 run

- Status: Accepted
- Date: 2026-10-20

## Context

The S8-K7 preregistration requires cross-fitting for primary AIPW and defines propensity support `(0.01, 0.99)` with a maximum stabilized-weight diagnostic of 10. The implementation instead fits and predicts nuisance models on the same cohort, clips to `[0.02, 0.98]`, and truncates weights at the 99th percentile without enforcing the registered maximum. Its E-value point estimate uses the bootstrap mean, undefined risk ratios become 1.0, and the run lacks a source-SHA manifest, registered seeds, and a canonical frozen-access record. The full audit is `docs/audits/K7-S8-IMPLEMENTATION-AUDIT-2026-10.md`.

## Decision

Retire S8-K7-001 as current causal/model-selection evidence. Preserve its outputs and do not infer or backfill missing provenance. Disable the old runner before data generation and report writes. A replacement must use a new ID, preregistration, seeds, source-bound access log, tested estimator contract, and run manifest.

## Consequences

The old reported estimates remain historical and do not establish that the registered cross-fitted estimator passed. No new synthetic cohort was generated by this disposition change. The replacement study remains required work under Q-7 package F/G.
