# ADR-0035: Explicit synthetic population profiles and censor-aware landmark labels

## Status
Accepted for this research rerun; all results remain synthetic.

## Context
The simulator embedded patient-mix assumptions in Python as Nigerian priors despite the source register downgrading E7/E12. The feature builder also assigned early-censored landmarks to the negative class, and downstream classifiers had no contract preventing censored rows from being fitted as negatives. These behaviors invalidate model selection and prior performance claims.

## Decision
1. Move baseline population assumptions to versioned JSON profiles. The default compatibility profile is named `legacy_synthetic_v0` and explicitly disclaims population calibration. New model tuning uses `balanced_synthetic_v1`, a neutral stress-test profile.
2. Preserve observed recurrence as event code 1, terminal competing events as code 2, and censoring/loss to follow-up as code 0. A horizon label is missing when follow-up ends before the horizon without a known event; loss to follow-up before a later recurrence censors that recurrence.
3. Require explicit IPCW sample weights for learned binary classifiers whenever any horizon label is unknown. Normalize weights so repeated landmarks do not cause patients with more visits to dominate total training weight.
4. Keep historical study artifacts unchanged and retracted where already identified. New training results use an independently preregistered experiment and a fresh frozen test cohort. This PR does not retroactively validate prior benchmark reports.

## Consequences
Correcting censoring changes the labels and can reduce apparent model performance. Legacy fixed-AUC sanity assertions may fail; the failure is left visible and a proposal requests a preregistered, independent study as the performance gate. Existing results must not be described as reproduced under the corrected label contract until their named producers have been rerun.

## Scope and downstream rerun
Changed shared packages: `vigil-sim`, `vigil-ml`, and `vigil-eval`. This branch reruns simulator, feature, metric, canary, baseline, and K6 dense-world suites and prepares `EXP-CORE-ML-003`; EXP-CORE-ML-001 is retained only as an aborted run. Historical S1/S3/S9, K1/K2/K3/K4/K5/K6/M12, partner-analysis, and benchmark artifacts are not regenerated by this change; their applicability to corrected labels must be considered unknown or already retracted. No result from the new study is clinical evidence.
