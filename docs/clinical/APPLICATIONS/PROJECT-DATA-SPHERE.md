## Purpose
Use publicly available, de-identified comparator-arm or historical clinical-trial patient-level data in breast cancer to examine the shape of serial laboratory values and recurrence timing in trial settings, as one input to plausibility checks and to the design of a retrospective validation protocol (tier `T-P`).

## Data wanted
Breast-cancer trial datasets that include laboratory results (CDISC SDTM `LB`) and demographics (`DM`) with dates of progression or recurrence, if any exist. Which datasets qualify is not known until the catalogue has been read; the application will name specific datasets once it has.

## Honest limitations
Trial populations are selected, mostly Western, and monitored on trial schedules, which differ from routine outpatient care. Nothing derived from them will be presented as evidence about routine surveillance in Nigeria.

## Data management
Local encrypted storage; no redistribution; no re-identification; aggregate outputs only with small cells suppressed; the repository will hold no patient rows.
