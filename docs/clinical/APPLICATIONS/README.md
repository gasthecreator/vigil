# Data-access applications (DRAFTS, NOT SUBMITTED)

Three applications, drafted so that the owner can review, complete the bracketed fields and submit. **Nothing here has been submitted, signed or sent**, and nothing may be: each application needs the applicant's own identity, institutional affiliation and signature, which only the owner can supply (`docs/HANDOVER.md`, H-002).

| File | Resource | What the process requires (as retrieved on 2026-10-18) | What is still missing |
|---|---|---|---|
| `MIMIC-IV.md` | MIMIC-IV v3.1 on PhysioNet | Credentialed PhysioNet user; CITI "Data or Specimens Only Research" training; signed PhysioNet Credentialed Health Data Use Agreement 1.5.0 (source: the dataset page, https://physionet.org/content/mimiciv/3.1/) | Owner's PhysioNet account, CITI certificate, reference/supervisor details, signature |
| `SEER.md` | SEER Research Data via SEER*Stat | Register in the SEER Data Request System with an e-mail address, acknowledge the SEER Research Data Use Agreement and the SEER Treatment Data Limitations, verify the e-mail; each person who will access the data submits a separate request (source: https://seer.cancer.gov/data/access.html) | Owner's identity and e-mail, acknowledgement |
| `PROJECT-DATA-SPHERE.md` | Project Data Sphere | **Not verified**: the site is a JavaScript application whose text could not be retrieved; the process below is taken from the repository's earlier notes (`docs/data/ACCESS.md`) and must be checked at registration | Everything, plus confirmation of the process |

Rules for every application: state the real purpose and the real limits (these datasets contain no African outpatient surveillance series and no serial laboratory trajectories linked to recurrence dates, except where noted); promise only what the software enforces; never claim a clinical aim the project cannot support; keep every regulatory-style document `DRAFT-UNREVIEWED` until a qualified reviewer has seen it.
