# API reference

The committed OpenAPI document is [`openapi.json`](openapi.json), regenerated by `scripts/export_openapi.py` and checked for drift in CI.

Download or open that JSON in any OpenAPI viewer. The running API also serves interactive Swagger UI at `/docs` in the local profile.

Sample public routes (always in schema): `GET /`, `GET /health`. Ops probes `GET /live`, `GET /ready`, `GET /metrics` ship in the process but stay out of the schema until [PROP-0007](../proposals/PROP-0007-observability-public-probes.md) lands.
