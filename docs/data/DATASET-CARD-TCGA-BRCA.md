## 1. Description
TCGA Breast Invasive Carcinoma (BRCA) is a public cancer genomics resource. Vigil does not vendor the data; operators obtain it under TCGA / GDC policies.

## 2. Intended use in Vigil
Optional research evaluation. Results must cite TCGA-BRCA explicitly and remain labelled non-clinical for Vigil product claims.

## 3. Limitations
- Bulk omics are not the longitudinal lab/symptom modality of the Vigil core pathway.
- No claim that Vigil improves outcomes on TCGA cohorts.
