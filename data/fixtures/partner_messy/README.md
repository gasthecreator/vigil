# SYNTHETIC messy partner dataset

Invented data, fixed seed, written by `scripts/make_messy_partner_dataset.py`. Nothing here describes a real patient. `INJECTED_FAULTS.json` lists every defect that was injected and the rejection code it must produce.
The `hl7/` files contain a made-up patient name on purpose: they rehearse the on-site converter, which is the only place a name may exist.
